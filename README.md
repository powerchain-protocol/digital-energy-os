# PowerChain SDK

Enterprise-grade blockchain SDK monorepo.

## Overview

PowerChain is a modular SDK ecosystem for JavaScript, TypeScript, Python, Go, Rust, Flutter, Node.js, React, Vue, Angular, CLI tooling, testing, and code generation.

## Packages

- @powerchain/web3.js
- @powerchain/sdk
- @powerchain/react
- @powerchain/react-ui
- @powerchain/vue
- @powerchain/angular
- @powerchain/node
- @powerchain/python
- @powerchain/go
- @powerchain/rust
- @powerchain/flutter
- @powerchain/cli
- @powerchain/testing
- @powerchain/codegen
