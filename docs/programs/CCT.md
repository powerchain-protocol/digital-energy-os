# PowerChain CCT v1.0.0

CCT is the PowerChain Carbon Credit Token on Solana Token-2022. The framework uses evidence-backed issuance intents and controlled retirement. `POWERCHAIN_CCT_PROGRAM_ID`, `POWERCHAIN_CCT_MINT` and `POWERCHAIN_CCT_AUTHORITY` are deployment-gating configuration values.

A token receipt is not automatically a legally recognized carbon certificate; applicable methodology and registry rules remain authoritative.
