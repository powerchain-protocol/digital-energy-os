# PowerChain Control Plane v1.0.0

The Control Plane is the shared authority boundary for identity, permissions, policy, context, approvals and audit before execution gateways.

Agent autonomy is explicit:

0. READ
1. ANALYZE
2. PREPARE
3. REQUEST APPROVAL
4. EXECUTE WITH PRE-AUTHORIZATION
5. AUTONOMOUS — only for tightly scoped low-risk workflows where policy permits it

The canonical Energy Analyst is capped at level 2. It can analyze telemetry and prepare reports/actions but cannot sign wallets, transfer treasury value, mint tokens or execute Local Energy trades.

Action Intent → policy decision → approval when required → execution gateway. AI output never becomes direct economic or device authority.
