# PowerChain CCT Registry v1.0.0

Deployment-gated Solana program boundary for PowerChain Carbon Credit Token (CCT) evidence commitments, issuance authorization and retirement receipts.

The canonical token standard is Token-2022. The program must not mint carbon attributes without a verified methodology/evidence reference and explicit PowerChain approval. `POWERCHAIN_CCT_PROGRAM_ID` and `POWERCHAIN_CCT_MINT` remain deployment-blocking configuration values until real addresses are deployed.
